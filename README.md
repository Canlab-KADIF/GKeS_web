# GKeS_web

`RoadInsight`는 자율주행 비정상 주행 데이터를 탐색하고 확인하기 위한 Flutter Web 기반 클라이언트입니다.
GKeS API와 연동하여 주행 상황 설명 검색, 조건 필터링, 상세 데이터 조회, 영상/지도 확인 기능을 제공합니다.

## 주요 기능

- 주행 데이터 검색 및 조건 기반 필터링
- 주행 영상, 지도, 메타데이터 상세 조회
- 선택한 데이터 패키지 다운로드

## 실행

```bash
flutter pub get
flutter run -d chrome
```
